# Let's make the work easier

I combine geospatial experience with practical software development to help people spend less time on repetitive tasks and get more value from their data.

If you have a workflow that costs too much, takes too many manual steps, or does not quite fit the software you use, I am interested in helping you improve it.

## What I can help with

| Need | A useful starting project |
| --- | --- |
| Repeated data entry or file handling | A script or small application that validates, converts, or organises your files. |
| Reports assembled across several tools | A workflow that brings structured records, photographs, maps, and exports together. |
| Field observations that are hard to use in the office | A collection and export workflow suited to your forms, attributes, and GIS. |
| Survey data waiting to become an answer | Point-cloud processing, terrain and bathymetric modelling, profiles, volumes, or deviation analysis. |
| An expensive or inflexible tool for a narrow task | A scoped alternative or an extension to an existing open-source tool, assessed against what you actually need. |
| A prototype that needs to fit your team | Custom features, data integration, setup, documentation, and a defined support arrangement. |

## A small, clear first step

**Start with the task.** Show me what you do today, where it slows down, and what a useful result looks like. An anonymised example file or a short walkthrough is often more useful than a long specification.

**Agree the scope.** We define the inputs, output, platform, acceptance criteria, and budget before starting a paid project. A focused first milestone makes it easier to evaluate the result before expanding the work.

**Build around the real workflow.** The aim is a tool or deliverable you can use, with clear instructions and an agreed handover. Ongoing changes and support can be scoped separately.

## Open tools, paid expertise

I want to make useful software free and open wherever practical. My commercial work is the expertise around it: building a specific solution, adapting it to your data, integrating it with your workflow, and helping you keep it useful.

An existing open-source tool may already solve most of the problem. If it does, configuring or extending it can be a better starting point than building everything again. We can agree the source availability and licence for custom work as part of its scope.
